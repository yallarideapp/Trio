# الكود — TRIO Mobile

## الترتيب
| المسار | شو فيه |
|---|---|
| `site/index.html`، `site/styles.css`، `site/src/app.js` | الموقع: الرئيسية، الأجهزة والفلاتر، العروض، صفحة الجهاز والخيارات، المفضلة، السلة، إتمام الطلب، الصيانة، التبديل، زورونا. عربي/إنجليزي. |
| `site/src/store.js` | طبقة البيانات: نسخة **live** بتحكي مع `/api/*`، ونسخة **demo** بتحفظ كل شي بالمتصفح. بتنختار وقت البناء. |
| `site/admin/` | لوحة التحكم `/admin/`: الطلبات، الأجهزة والأسعار والصور، الإعدادات، النشر. |
| `shared/catalog.js` | الأجهزة والأسعار المشحونة (من منشورات تريو). بتستعمل لحد أول نشر من اللوحة. |
| `shared/pricing.js` | حساب السلة بالفلس، حدود العدد، أرقام الموبايل. **نفس الملف** للموقع والـ Worker. |
| `shared/labels.js` | كلمات الحالة والكفالة والملاحظات وقائمة المحافظات. |
| `worker/src/` | الـ Worker: `index.ts` (التوجيه)، `content.ts` (المحتوى المنشور وتنظيفه)، `orders.ts` (الطلبات والإيميل)، `admin.ts` (الدخول والجلسات والنشر والصور)، `util.ts`. |
| `migrations/` | جداول قاعدة البيانات D1. |
| `wrangler.jsonc` | إعدادات Cloudflare (أرقام D1 وKV بتنحط هون). |
| `tools/build.mjs` | البناء: `live` لـ `dist/`، و`demo` للنسخة المحمولة. |
| `tools/package-store.sh` | بيبني Demo والـ ZIPs ومجلد التسليم. |
| `tests/check.mjs` | فحص سريع بدون متصفح. |

## التشغيل محلياً
```sh
npm install
npm run db:local                         # جداول قاعدة بيانات محلية
printf 'SETUP_CODE=local-setup-code\n' > .dev.vars   # رمز إعداد للتجربة فقط (ما بنرفعه)
npm run dev                              # http://127.0.0.1:8787  و /admin/
npm test
```

## الأمان باختصار
- الأسعار بتنحسب على السيرفر من المحتوى المنشور؛ المجموع من المتصفح لازم يطابق بالفلس.
- 5 قطع لكل سطر، 20 سطر لكل طلب، 10 طلبات بالساعة لكل IP (و300 لكل الموقع).
- رقم الطلب من عدّاد بنفس العملية (batch) مع الطلب، فما في رقمين متشابهين. إعادة الإرسال بنفس الرمز بترجّع نفس الطلب.
- لوحة التحكم: رمز إعداد مرة وحدة، كلمة سر 16 حرف أو أكثر محفوظة بـ PBKDF2-SHA-256 (20,000 مرة حتى تضل تحت حد المعالجة المجاني 10ms)، كوكي HttpOnly Secure SameSite=Strict، 5 محاولات غلط لكل IP كل 15 دقيقة.
- كل طلب بغيّر بيانات لازم يكون من نفس الموقع (Origin). JSON بس، وحجم محدود.
- الصور WebP بس، 1 ميغا كحد أقصى، بتتخزن بـ KV وبتنخدم بـ headers آمنة.
- المحتوى المنشور بنعاد بناؤه من حقول معروفة بس (أطوال محدودة، روابط https بس).
- ولا سر بينحط بالكود أو بالمتصفح: الأسرار بـ Cloudflare Secrets.


## نسخة GitHub Pages الحالية

للموقع المنشور على GitHub استعمل `npm run build:pages` ثم `npm test -- --pages`. الناتج في `../website/`. هذه نسخة تصفح وتواصل: لا تحفظ طلبات تجريبية ولا تتصل بواجهة Worker. السلة تفتح التواصل المباشر لتأكيد الأجهزة. لوحة التحكم والطلبات المشتركة تحتاج نشر Worker وإعداد D1 وKV بشكل منفصل.

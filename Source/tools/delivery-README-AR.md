# TRIO Mobile — ملف التسليم

| الملف | شو هو |
|---|---|
| `Demo/` | **النسخة التجريبية**: فك الضغط ودبل كليك على `Open-demo.html`. فيها زر للوحة التحكم. |
| `Trio-website-source.zip` | الكود كامل لرفعه على GitHub والنشر على Cloudflare. |
| `Cloudflare-guide.md` | خطوات التشغيل على Cloudflare مجاناً (حساب، GitHub، قاعدة بيانات، أول دخول، دومين). |
| `Documents/` | من وين إجت الأسعار (`SOURCES.md`) والصور (`IMAGE-ASSETS.md`)، والصور الأصلية. |

## شو الحقيقي وشو التجريبي
- **حقيقي**: الأجهزة والأسعار والحالات والكفالات من منشورات تريو على إنستغرام (لحد 17 تشرين الأول 2026). العنوان والرقم والروابط من صفحة تريو.
- **تجريبي**: بالـ Demo، الطلبات والتعديلات بتضل على المتصفح بس. بالنسخة المنشورة على Cloudflare بتصير حقيقية وبتوصل للوحة التحكم.
- **لازم يتأكد قبل الإطلاق**: رقم الواتساب، أسعار منشورات آب للـ iPad، وأي سعر تغيّر بعد آخر منشور (التفاصيل بـ `Documents/SOURCES.md`).

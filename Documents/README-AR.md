# المستندات
- `SOURCES.md` — كل منشور إنستغرام انأخذ منه سعر أو معلومة، والقرارات اللي لازم المحل يأكدها.
- `IMAGE-ASSETS.md` — من وين إجت كل صورة جهاز، وأي صورة مستعملة لأكثر من موديل.
- `IMAGE-REPAIRS.json` — الصور اللي انبدلت بصور الشركة المصنّعة: رابط كل صورة وبصمتها.
- `HOME-CATEGORY-ASSETS.json` — صور أقسام الصفحة الرئيسية ومصادرها.
- `Media-originals/` — صور المنشورات الأصلية زي ما هي.
